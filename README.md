# ⚡ Pokémon GO Element & Type Effectiveness Guide

Panduan interaktif & kalkulator efektivitas tipe/elemen Pokémon GO lengkap untuk pertarungan Raid, Gym, Team GO Rocket, dan GO Battle League (PvP).

## 🌟 Fitur Utama

- **🛡️ Kalkulator Defender (Lawan)**: Mendukung Single & Dual Type dengan perhitungan akurat Pokémon GO:
  - 💥 **2.56x** (Double Super Effective / Double Weakness)
  - ⚠️ **1.60x** (Super Effective / Weakness)
  - ⚪ **1.00x** (Neutral)
  - 🛡️ **0.625x** (Resistance / Not Very Effective)
  - 🛑 **0.391x** (Double Resistance / Immunity Tier)
  - ⛔ **0.244x** (Triple Resistance)
- **⚔️ Kalkulator Attacker (Serangan)**: Mengetahui efektivitas jurus Anda terhadap tipe lawan beserta bonus cuaca (*Weather Boost* +20% damage).
- **📖 Pokédex Lengkap (1.279 Pokémon)**: Database lengkap dari Gen 1 hingga Gen 9 (#0001 Bulbasaur s/d #1025 Pecharunt), termasuk bentuk Alolan, Galarian, Hisuian, Paldean, dan Mega Evolution.
- **🖼️ Gambar HD Resmi (*Official Artwork*)**: Dilengkapi gambar HD transparan dan thumbnail di dropdown pencarian.
- **🚀 Cheat Sheet Dialog Team GO Rocket**: Temukan tipe Pokémon Grunt dan counter terbaiknya hanya dari kalimat dialog mereka.
- **☀️ Panduan Cuaca (*Weather Boost*)**: 7 kondisi cuaca in-game dan efek bonus damage + level spawn.
- **📊 Matriks Interaktif 18 × 18**: Tabel grid lengkap relasi seluruh 18 tipe Pokémon.
- **📱 100% Responsif di HP / Mobile**: Tampilan ramah jempol, anti auto-zoom di iOS, dan tombol melayang kembali ke atas.
- **⚡ 100% Offline Ready**: Tanpa ketergantungan framework eksternal, sangat ringan (~135 KB).

## 🚀 Cara Menjalankan

### 1. Langsung di Browser (Offline)
Cukup buka file `index.html` atau `pokemon_go_type_chart.html` menggunakan browser apa saja (Google Chrome, Microsoft Edge, Safari, Firefox).

### 2. Live Online via GitHub Pages
1. Masuk ke repository GitHub ini: `Settings` > `Pages`.
2. Pada bagian **Branch**, pilih `main` (atau `master`) dan folder `/ (root)`.
3. Klik **Save**.
4. Website akan langsung aktif secara publik di:
   ```
   https://andre9403.github.io/AndreAg/
   ```
